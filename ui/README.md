# SafeFlow UI

React/Vite operator console for the hackathon demo.

Rules:

- Keep UI code under `ui/src/`.
- Use `VITE_API_BASE_URL` for backend URL.
- Do not put safety logic, policy decisions, or fixture mutation in React.
- Use backend APIs for workflow execution and approvals.

Commands:

```bash
npm install
npm run dev
npm run build
npm run lint
```
