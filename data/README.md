# Data

Structured research datasets, deterministic fixtures, benchmark tasks, and evaluation results live here.

## Current Research Datasets

- `phase1/framework_database.csv` - AI agent framework database.
- `analysis/*.csv` - issue analysis, gap ranking, and industrial problem matrices.

## MVP Runtime Data

```text
data/
+-- fixtures/
|   `-- support/
+-- benchmark/
|   `-- support_demo.jsonl
+-- results/
+-- phase1/
`-- analysis/
```

- `fixtures/support/` contains deterministic P0 support workflow states.
- `benchmark/support_demo.jsonl` contains the starter evaluation tasks.
- `results/` is for generated workflow and evaluation outputs.
